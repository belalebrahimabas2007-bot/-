# إنجاز — تطبيق الطلاب ولوحة الإدارة

هذا مستودع جديد ومستقل لمشروع إنجاز، مخصص لتطبيق الطلاب ولوحة الإدارة والخادم المشترك.

## الحالة
المشروع في مرحلة التجربة والتطوير. لا تستخدم بيانات طلاب حقيقية أو معلومات دفع حقيقية قبل مراجعة الأمان والاستضافة.

## التنظيم المخطط
- `student/`: واجهة الطلاب
- `admin/`: لوحة الإدارة
- `server/`: واجهة البرمجة وقاعدة البيانات

> لا علاقة لهذا المستودع بمستودع `mozakerati` السابق.
